## 1. 产品概述
轻量级项目管理工具，帮助小团队追踪项目任务进度、提交代码审查并生成工作统计看板。解决团队协作中任务分散、进度不透明等常见问题。目标用户为5-20人的开发团队。

## 2. 核心功能

### 2.1 用户角色
| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 团队成员 | 用户名+密码注册 | 创建/编辑任务、发表评论、提交代码审查、查看统计 |

### 2.2 功能模块
1. **看板页面**：任务卡片管理，拖拽状态流转，创建/编辑任务
2. **任务详情面板**：完整任务信息展示，评论区域，@提醒
3. **代码审查页面**：文件目录树上传，行内评论，审查状态标记
4. **统计看板页面**：团队进度统计卡片，成员完成量柱状图，任务趋势折线图
5. **登录/注册页面**：用户认证

### 2.3 页面详情
| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 登录/注册 | 认证表单 | 用户名密码注册登录，表单验证 |
| 看板页面 | 状态列 | 四列：待办/进行中/审查中/已完成，顶部显示名称和计数徽标 |
| 看板页面 | 任务卡片 | 毛玻璃背景，优先级颜色标签，悬停上浮动画，拖拽交互 |
| 看板页面 | 创建任务表单 | 填写标题、描述、截止日期、指派人、优先级 |
| 任务详情 | 信息面板 | 展示完整任务信息，侧边滑出面板 |
| 任务详情 | 评论区域 | 文字评论列表，头像/用户名/时间戳，@提醒弹窗 |
| 代码审查 | 文件目录树 | 以树形结构上传代码片段，显示行号 |
| 代码审查 | 行内评论 | 点击行号添加评论气泡，标记通过/需修改 |
| 统计看板 | 统计卡片 | 总任务数/已完成数/逾期数/平均完成天数 |
| 统计看板 | 柱状图 | 各成员完成任务数量对比 |
| 统计看板 | 折线图 | 近7天每日新增任务趋势 |

## 3. 核心流程
用户注册登录后进入看板页面，在看板上创建任务卡片并拖拽至对应状态列。点击卡片展开详情面板可查看完整信息和评论。提交代码审查后任务状态自动更新为审查中。统计看板实时展示团队整体进度数据。

```mermaid
flowchart TD
    "注册/登录" --> "看板页面"
    "看板页面" --> "创建任务卡片"
    "创建任务卡片" --> "拖拽至状态列"
    "拖拽至状态列" --> "点击卡片查看详情"
    "点击卡片查看详情" --> "发表评论/@提醒"
    "点击卡片查看详情" --> "提交代码审查"
    "提交代码审查" --> "行内评论+标记"
    "行内评论+标记" --> "状态自动更新为审查中"
    "看板页面" --> "统计看板"
    "统计看板" --> "查看团队进度数据"
```

## 4. 用户界面设计

### 4.1 设计风格
- 主背景色：#1A1A2E，卡片背景色：#16213E
- 强调色：#E94560（红粉色）、#0F3460（深蓝色）
- 字体：JetBrains Mono（代码/数字）+ Noto Sans SC（中文界面）
- 布局：左侧导航栏 + 右侧内容区，看板横向滚动
- 卡片圆角8px，微阴影，毛玻璃效果

### 4.2 页面设计概览
| 页面名称 | 模块名称 | UI元素 |
|----------|----------|--------|
| 看板页面 | 状态列 | 深色背景，顶部状态名+徽标，横向滚动，垂直堆叠卡片 |
| 看板页面 | 任务卡片 | backdrop-filter: blur(4px)，hover Y轴-4px上浮，优先级色条 |
| 任务详情 | 侧边面板 | 右侧滑出，半透明遮罩，评论列表，@选择框弹出 |
| 代码审查 | 代码区 | 行号+代码内容，行号悬停高亮，点击添加评论气泡 |
| 统计看板 | 图表区 | recharts柱状图/折线图，淡入动画，渐变色填充 |
| 登录/注册 | 表单 | 居中卡片，渐变边框聚焦效果 |

### 4.3 响应式
- 桌面优先，移动端看板变为垂直布局
- 侧边面板在移动端全屏展示
- 统计图表自适应宽度

### 4.4 动效
- 拖拽时卡片缩小+半透明占位
- 放置后卡片回弹动画（CSS transition）
- 评论框聚焦底部边框渐变光效
- 统计图表淡入动画
- 骨架屏占位加载
